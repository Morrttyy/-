Number Guessing Game

A simple number guessing game developed with Python and SQLite.

Description

In this project, the user tries to guess a randomly generated number between 1 and 20.

The program stores player information and game results in an SQLite database.

Features

- Player registration using a player code
- Random number generation
- Guessing with hints
- Saving game results in SQLite
- Showing previous game records
- Showing the player's best attempt

Technologies

- Python
- SQLite
- sqlite3

Project Structure

- "main.py" — Handles the game flow and user interaction.
- "data_manager.py" — Handles database connection and database operations.
- "database.db" — SQLite database used to store player and game information.
